# GRE Vocab — GregMat 30 Groups

Personal GRE vocabulary trainer built around GregMat's 30-group word list (900 words). Designed for a 4-session daily study routine.

## 🚀 Deploy to GitHub Pages (5 minutes)

1. Create a new GitHub repo (e.g. `gre-vocab`)
2. Upload: `index.html`, `data.js`, and the `media/` folder
3. Go to **Settings → Pages → Source → Deploy from branch → main / (root)**
4. Bookmark `https://yourusername.github.io/gre-vocab` on your phone

Works fully offline once loaded. All progress saved in browser localStorage.

## 📅 Daily 4-Session Routine

| Session | Button | What it does |
|---------|--------|--------------|
| Morning (wake up) | 📖 Morning Review | Learn today's 30 words — flashcard mode |
| Lunch | ☀️ Lunch Repeat | Go through same 30 words again |
| Evening | 🎯 Evening Quiz | Quiz on today's 30 words only |
| Night (before sleep) | 🌙 Night Quiz | Quiz on ALL words learned so far |

## ✨ Key Features

- **30 groups × 30 words** — one group per day, auto-tracked by date
- **Flashcards with GregMat images** — real images from the GregMat Anki deck
- **Definitions + Extended definitions + Example sentences** — all from GregMat
- **⭐ Hard word tagging** — press `S` on any card or click ☆ to mark a word as hard
- **Hard word quiz** — dedicated quiz mode for only your starred words
- **3 quiz question types** — choose the word, choose the definition, type the word
- **Word detail modal** — click any word anywhere to see full details + hear pronunciation
- **Day jump** — manually set your current day for review of past groups
- **Progress dashboard** — group grid shows % known per group, star indicator if hard words present

## ⌨️ Keyboard Shortcuts (desktop)

| Key | Action |
|-----|--------|
| `Space` | Flip flashcard |
| `→` Right arrow | Mark "Know It" |
| `←` Left arrow | Mark "Still Learning" |
| `S` | Toggle ⭐ hard tag on current card |
| `Enter` | Next quiz question |
| `Esc` | Close modal |
